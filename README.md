# alex-jersey

Alex Jersey Shop — FIFA World Cup 2026 jersey e-commerce (Nepal). React + Vite frontend, Node.js API.

## Setup

```bash
# Client (storefront)
cd client && npm install && npm run dev

# Server (API)
cd server && npm install && cp .env.example .env && npm run dev

# Admin panel (separate app, port 3001)
cd admin && npm install && cp .env.example .env.local && npm run dev
```
